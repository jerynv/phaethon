Pre-alpha desktop build. Phaethon is still in development and is not ready for real data.

New in 0.3.0

  • Memory that fades when it stops mattering. Events, temporary states, tasks and notes come up only when they're relevant, and close once they're done. A profile for you and one per space.
  • People. A card per person with aliases ("my boss"), links and history; people you email are added when their name is found.
  • Mail. Apple Mail and Outlook through the Mail app. Drafts never send on their own: Send starts a visible one-minute countdown you can stop or edit.
  • Automations. Reminders, a daily digest, memory review and your own schedules, with pause.
  • Files. A files view for every space.
  • In the menu bar. Closing the window leaves Phaethon running in the menu bar for reminders, timed sends and automations, with native notifications and an option to open at login.
  • A slimmer title bar, smooth icon edges, Settings without a tab, and content that fades under the bar instead of being cut off.

Download the installer for your operating system from the assets below:

  • macOS: Phaethon-0.3.0-mac-arm64.dmg (Apple Silicon) or Phaethon-0.3.0-mac-x64.dmg (Intel)
  • Windows: Phaethon-0.3.0-win-x64.exe
  • Linux: Phaethon-0.3.0-linux-x86_64.AppImage or Phaethon-0.3.0-linux-amd64.deb

This build isn't signed with an Apple Developer certificate, so macOS blocks it the first time you open it. Open System Settings › Privacy & Security and choose Open Anyway, or run xattr -dr com.apple.quarantine /Applications/Phaethon.app. Windows SmartScreen may also warn: choose More info › Run anyway.

Phaethon 0.1.x can't update itself to this version: download and install it once by hand.
