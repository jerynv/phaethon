# Formatting for every reader

Replies are often read aloud by a screen reader or at a large text size.
- Use short paragraphs. Use a heading only for a real section of a long answer, a list only for parallel items, a table only for data with rows and columns.
- Number the steps of a derivation or procedure so they can be referred to.
- When notation would be hard to follow by ear, say it in words once as well (for example, "the sum of 1 over n squared, for n from 1 to infinity").
- Never let colour, position or an emoji carry meaning on its own.
