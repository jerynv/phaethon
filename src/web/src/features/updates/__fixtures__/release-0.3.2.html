Download the installer for your operating system from the assets below. Phaethon 0.2 and later can also update from inside the app.

  • The Mac app is signed and notarized by Apple. It opens like any other downloaded app: macOS asks once whether to open it, with no trip to System Settings. Updates install in place.
  • Every AI service on one page. Settings › AI & Models lists Claude, ChatGPT, Gemini, OpenRouter, Groq, local models and your own server at once, each saying Ready or Set up. Claude, ChatGPT and Gemini connect with a plan you already pay for or an API key.
  • Automatic fallback. If a model can't be reached, your chat carries on with another model you've set up and says which one took over. You can turn it off in Settings.
  • An update window. When a new version is out, Phaethon shows what changed and installs it in one click; after updating, What's new shows once.
  • Coding agents start more reliably. Codex works across older and newer versions, Claude Code installed through npm works on Windows, and a reply that fails to start shows the agent's own error. Thanks to @Lreddell.
  • School is ready for study tools. The built-in School space has study tools on from the start, and Grades, Plan and Study refresh when you come back to them.
  • Formulas like $17 + 23 = 40$ render as math, and the plan's date picker moves with the arrow keys across months.

Phaethon 0.1.x can't update itself to this version: download and install it once by hand.
